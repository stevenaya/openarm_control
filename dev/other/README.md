# Other Development Experiments

This directory preserves development material that is not used by the final
report in [`../../exp`](../../exp/README.md).

| Path | Contents |
|---|---|
| `final_study/` | Earlier diagnostic scripts, superseded report preview, and non-final experiment results |
| `python_cache/` | Generated Python bytecode moved out of the active experiment directories |

The historical scripts under `final_study/` are retained for reference. They
were exploratory programs, may contain paths from their original workspace,
and are not part of the supported final-report reproduction workflow.

The former `dev/results/` tree contained only empty directories from older
2026-07-28/29 studies, so no result files were available to archive.
